RPi_Yahoo_News_Server v0.1.0

Yahooニュース シンプル v6.7.1 の画面構成をRaspberry Pi向けWebアプリとして分離。
- 2chまとめとは別サービス rpi-yahoo-news.service
- ポート 8768
- 記事本文・画像・コメントの保存キャッシュなし
- 一覧は表示時にYahooへ取得、表示中は1分ごとに新着確認
- 手動「更新」は即時取得
- iPad/PC: 一覧＋本文の2ペイン
- iPhone: 一覧→本文の1ペイン、本文上部「← 一覧」
- アクセスランキング / ヤフコメランキング
- 記事写真、コメント最大30件
